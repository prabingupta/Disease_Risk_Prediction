# Disease Risk Prediction

## Project Overview
This project predicts the risk of diabetes using machine learning techniques on the Pima Indians Diabetes Dataset. The aim of this project is to analyze medical data and build predictive models that can help identify whether a patient is likely to have diabetes based on diagnostic measurements.

## Dataset
Dataset used:
- Pima Indians Diabetes Dataset
- File: diabetes.csv

Kaggle Dataset Link:
https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database

Features include:
- Pregnancies
- Glucose Level
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age
- Outcome (Diabetic or Not)
